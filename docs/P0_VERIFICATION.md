# P0 운영 검증 가이드

> 대표 직접 검증용. 총 소요시간 약 20분.
> 검증 URL: https://supermujin.ai

---

## 1. 센터 로그인 검증 (5분)

### 1-1. 센터 코드 확인
- 마스터 계정 로그인: `master` / `master1234`
- 좌측 메뉴 "센터 관리" 클릭
- 등록된 센터의 **센터 코드** 확인 (예: `C001`)

### 1-2. 센터 코드로 로그인
- 로그아웃
- 아이디: `C001` (센터 코드)
- 비밀번호: `C001` (초기 비밀번호 = 센터 코드)
- **확인 사항**:
  - 로그인 성공
  - 좌측 메뉴: 대시보드, 셀러 관리, 발주 컨펌, 입금 관리, 방송 관리, 방송 캘린더, 상품 관리, 바코드
  - 대시보드 제목: "센터 대시보드"
  - KPI 라벨: "센터 매출", "센터 판매 건수" 등

### 1-3. 비밀번호 변경 (선택)
- 우측 상단 프로필 → 설정
- 현재 비밀번호: `C001`
- 새 비밀번호 입력 → 변경 완료 확인

---

## 2. 셀러 발주 플로우 (5분)

### 2-1. 셀러 로그인
- 로그아웃 후 셀러 계정 로그인: `seller1` / `seller1234`
- **확인 사항**:
  - 좌측 메뉴: 내 통계, 방송 신청, 방송 캘린더, 내 발주, 상품 제안, 샘플 요청, 바코드
  - 대시보드 제목: "내 통계"
  - KPI 라벨: "내 매출", "내 판매 건수" 등

### 2-2. 발주 등록
- "내 발주" 클릭
- "엑셀 업로드" 클릭
- 템플릿 다운로드 → 작성 → 업로드
- **외상거래 테스트**: "외상거래 (입금 단계 생략)" 체크박스 확인
  - 체크 시: 발주 생성 후 `paymentStatus = PAID` (입금 스킵)
  - 미체크 시: 발주 생성 후 `paymentStatus = UNPAID` (기본)

### 2-3. 발주 목록 확인
- "내 발주" 페이지에서 등록한 발주 확인
- **발주상태 컬럼**: "컨펌대기" 표시

---

## 3. 센터 발주 컨펌 (5분)

### 3-1. SUB_MASTER 로그인
- 센터 코드 또는 SUB_MASTER 계정으로 로그인

### 3-2. 발주 컨펌 탭 확인
- "발주 컨펌" 메뉴 클릭
- **확인 사항**:
  - 2개 탭: "본사 제품 발주" / "센터 제품 발주"
  - "본사 제품 발주" 탭: 액션 버튼 없음 (읽기 전용)
  - "센터 제품 발주" 탭: 컨펌/반려/입금확인/출고/취소 버튼 표시

### 3-3. 컨펌 처리
- "센터 제품 발주" 탭에서 컨펌대기 발주 선택
- "컨펌" 버튼 클릭 → 확인 다이얼로그 → 확인
- **확인 사항**: 발주상태 "컨펌대기" → "입금대기"

### 3-4. 반려 처리 (선택)
- 다른 발주의 "반려" 버튼 클릭
- 반려 사유 입력 → "반려 확인" 클릭
- **확인 사항**: 발주상태 → "반려"

---

## 4. 입금 처리 (3분)

### 4-1. 입금 관리 페이지
- SUB_MASTER로 "입금 관리" 메뉴 클릭
- **확인 사항**:
  - 요약 카드: 미입금 건수, 미입금 총액, 입금완료 건수
  - 기본 탭: "미입금"
  - 3개 탭: 미입금 / 입금완료 / 전체

### 4-2. 개별 입금확인
- 미입금 목록에서 특정 발주의 "입금확인" 버튼 클릭
- **확인 사항**: 해당 발주가 목록에서 사라짐 (입금완료 탭으로 이동)

### 4-3. 일괄 입금확인 (선택)
- 체크박스로 여러 건 선택
- 상단 "N건 일괄 입금확인" 버튼 클릭
- **확인 사항**: 선택한 건 모두 입금완료 처리

---

## 5. 출고 처리 (3분)

### 5-1. 발주 목록에서 출고
- "발주 컨펌" 페이지로 이동
- 입금완료(출고대기) 상태의 발주에서 "출고" 버튼 클릭
- **확인 사항**: 발주상태 "입금완료(출고대기)" → "출고완료"

---

## 6. 마스터 모니터링 (2분)

### 6-1. 마스터 로그인
- `master` / `master1234` 로그인
- **확인 사항**:
  - 대시보드 제목: "통계 대시보드"
  - KPI 라벨: "총 매출", "판매 건수" 등
  - ONEWMS 연동 상태 카드 표시

### 6-2. 사용자 관리
- "사용자 관리" 메뉴 클릭
- "사용자 추가" 버튼 → Dialog 표시 확인
- **확인 사항**:
  - 역할 선택: SUB_MASTER / SELLER
  - 센터 선택 드롭다운
  - 소속 센터 컬럼 표시

### 6-3. 발주 관리
- "발주 관리" 메뉴 클릭
- **확인 사항**:
  - 3개 탭: 전체 / 업체발주서 (본사 책임) / 관리메이트 (센터 책임)
  - 발주상태 컬럼: 한글 라벨 (컨펌대기, 입금대기 등)

---

## 7. 방송 신청 (2분)

### 7-1. 셀러 로그인 후 방송 신청
- "방송 신청" (방송 캘린더) 메뉴 클릭
- 날짜 클릭 또는 "방송 신청" 버튼 클릭
- **확인 사항**:
  - "방송 제목" 입력 필드 (신규)
  - "예상 상품 목록" 텍스트 영역 (신규)
  - 플랫폼, 메모 등 기존 필드

---

## 상태 흐름 요약

```
발주 생성 → 컨펌대기 (PENDING/UNPAID/PENDING)
    ↓ 컨펌
입금대기 (APPROVED/UNPAID/PENDING)
    ↓ 입금확인
입금완료(출고대기) (APPROVED/PAID/PENDING)
    ↓ 출고처리
출고완료 (APPROVED/PAID/SHIPPED)

반려: PENDING → REJECTED
취소: PENDING → CANCELLED
외상: 생성 시 PAID 세팅 → 입금 스킵
```
