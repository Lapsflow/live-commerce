## 📊 Phase 1: 회원가입 시스템

### ✅ 완료된 항목

| 항목 | PDF 스펙 | 현재 구현 | 상태 |
|------|---------|----------|------|
| 아이디 | 필수 | `username String @unique` | ✅ 완료 |
| 비밀번호 | 8자 이상 필수 | `passwordHash String` | ✅ 완료 |
| 이름 | 실명 필수 | `name String` | ✅ 완료 |
| 휴대폰번호 | 010-0000-0000 필수 | `phone String` | ✅ 완료 |
| 이메일 | 선택 | `email String? @unique` | ✅ 완료 |
| 센터 소속 | 필수 (없으면 가입 불가) | `centerId String?` | ⚠️ nullable |
| 센터코드 형식 | [01-17]-[4자리] | 검증 로직 존재 | ✅ 완료 |
| 방송 채널 | 2차 추가 정보 | `channels String[]` | ✅ 완료 |
| 월 평균 매출 | 2차 추가 정보 | `avgSales Int?` | ✅ 완료 |
| 판매 카테고리 | 2차 추가 정보 | `categories String[]` | ✅ 완료 |
| 활동 지역 | 2차 추가 정보 | `regions String[]` | ✅ 완료 |
| 방송 시간대 | 2차 추가 정보 | `timeSlots String[]` | ✅ 완료 |

### 🔴 Critical Gaps

**GAP-P1-01: 센터 소속 필수 검증 미흡**
- **PDF 요구**: "센터코드가 없으면 방송 불가", "모든 계정은 반드시 센터에 소속"
- **현재**: `centerId String?` (nullable)
- **영향**: MASTER는 센터 없이 생성 가능해야 하지만, SELLER는 필수
- **수정**: SELLER 회원가입 시 centerId 필수 검증 추가

**GAP-P1-02: 센터 승인 프로세스 미구현**
- **PDF 강조**: "센터가입권한 계약과 및 아이디와 계정을 받아야한다", "사업자등록증 등을 제출식으로 받아야한다"
- **현재**: 센터는 ADMIN이 자유롭게 생성 가능
- **영향**: 센터 승인 프로세스 없음
- **수정**: 센터 신청 → 검토 → 승인 플로우 추가 필요

## 📊 Phase 2: 바코드 스캔 시스템

### 🔴 Critical Gaps

**GAP-P2-01: AI 분석 수동 트리거 (최우선 수정 필요)**
- **PDF 명시**: "바코드 찍으면 자동으로 실행, 이게 기본입니다"
- **현재**: "AI 분석 시작" 버튼 클릭 필요
- **영향**: PDF의 핵심 철학 위반 - "바코드 한 번에 모든 정보"
- **수정**: `useMutation` → `useQuery`, 버튼 제거, 자동 실행

**GAP-P2-02: 네이버/쿠팡 수동 조회**
- **PDF 명시**: "기본적으로 항상 데이터가 떠 있어야 한다", "검색 버튼이 아니라"
- **현재**: 수동 버튼 클릭 또는 구현 안 됨
- **영향**: 방송 중 속도 저하
- **수정**: 바코드 스캔 시 자동 조회, 캐싱 구현

**GAP-P2-03: 가격 수정 가능**
- **PDF 명시**: "가격은 조회만 가능하고 수정은 불가능해야 합니다"
- **현재**: 상품 수정 API에서 가격 변경 가능
- **영향**: 마진 보호 실패, WMS 통제 불가
- **수정**: 상품 가격 필드를 읽기 전용으로 변경

**GAP-P2-04: WMS 기준 가격 관리 미구현**
- **PDF 요구**: "최초 판매가", "권장 판매가", "최대 판매가" 구조
- **현재**: `sellPrice`, `supplyPrice`만 존재
- **영향**: 가격 통제 체계 부족
- **수정**: 가격 필드 확장 및 검증 로직 추가

**GAP-P2-05: 색상 판단 시스템 미구현**
- **PDF 요구**: "재고 많을 → 초록, 부족 → 노랑, 위험 → 빨강, 한눈에 상태가 보이게"
- **현재**: 재고 숫자만 표시
- **영향**: 판단 자동화 부족
- **수정**: 재고 임계값 기반 색상 표시

**GAP-P2-06: 방송 중 주문 입력 미구현**
- **PDF 요구**: "방송 중물을 안에서 바로 입력 가능", "수량 입력 → 버튼 클릭 → 자동 금액 계산"
- **현재**: 별도 주문 페이지로 이동 필요
- **영향**: 방송 중 주문 입력 불편
- **수정**: 바코드 화면에 주문 입력 UI 추가

**GAP-P2-07: WMS 양식 엑셀 다운로드 미구현**
- **PDF 요구**: "나중에 엑셀 다운로드", "WMS필꺼 양식하고 동일거거"
- **현재**: 일반 엑셀 export만 가능
- **영향**: WMS 연동 불편
- **수정**: WMS 양식에 맞는 엑셀 export 추가

**GAP-P2-08: 자동 캐싱 미흡**
- **PDF 요구**: "한 번 조회한 데이터는 압장 시간 개선에서 빠르게 보여줘야"
- **현재**: React Query 캐싱은 있으나 최적화 부족
- **영향**: 재조회 시 속도 저하
- **수정**: 캐싱 전략 최적화 (1시간 staleTime)

**GAP-P2-09: UI 구조 불일치**
- **PDF 요구**: "상단(상품명/재고/마진) → 중간(AI/시세) → 하단(주문/방송)"
- **현재**: 다른 구조
- **영향**: 사용자 경험 불일치
- **수정**: PDF 스펙에 맞게 UI 재구성
