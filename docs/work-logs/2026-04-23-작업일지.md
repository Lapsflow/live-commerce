### 1. 쿠팡 Partners API 클라이언트 수정 완료 ✅

**문제 상황**
- 바코드 스캔 시 네이버 쇼핑 가격비교는 작동하나 쿠팡 결과가 항상 없음
- 고객이 "API 키 없이 된다"고 전달했으나, 확인 결과 공식 API는 키 필수

**원인 분석**
1. **API 키 미설정**: `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` 환경변수 없음
2. **HMAC 인증 형식 오류**: Bearer 토큰 방식 → CEA 형식이어야 함
3. **Rate Limit 오류**: 10,000/일 → 실제 10회/시간 (30+/시간 = 24시간 정지, 3회 정지 = 영구 차단)

**수정 파일**

| 파일 | 변경 내용 |
|------|----------|
| `lib/marketplaces/coupang/client.ts` | HMAC-SHA256 인증 완전 재작성 (CEA format), Rate limit 10/hour |
| `lib/marketplaces/coupang/config.ts` | 키 없을 때 throw 대신 `null` 반환 (graceful skip) |
| `lib/services/pricing/marketPricing.ts` | `createCoupangClient()` null 반환 시 안전 처리 (2곳) |

**쿠팡 Partners API 핵심 정보**
- 인증 헤더: `CEA algorithm=HmacSHA256, access-key=..., signed-date=..., signature=...`
- HMAC 메시지: `datetime + method + path + queryString`
- 타임스탬프: `yyMMddTHHmmssZ` (UTC)
- Rate limit: 10회/시간
- API 키 발급: partners.coupang.com (누적 매출 15만원 이상 필요)
- "키 없이 작동" 주장은 Danawa 웹스크래핑 방식(uju777/coupang-mcp)이며, 현재 503 에러로 작동 불가

### 3. 재고 수량 업데이트 버그 수정 완료 ✅ (설계 문서 #1)

**문제 상황**
- 바코드 스캔 → 입고/출고 → 재고 수량이 변하지 않음

**근본 원인**
1. **API 버그**: `/api/inventory/scan`에서 `ProductCenterStock.stock`은 업데이트하지만 `Product.totalStock`은 재계산하지 않음
2. **UI 버그**: 입고/출고 성공 후 `onClose()`만 호출하여 모달이 닫히고, 최신 재고가 표시되지 않음

**수정 파일 (4개)**

| 파일 | 변경 내용 |
|------|----------|
| `app/api/inventory/scan/route.ts` | Transaction 내 `Product.totalStock = SUM(all centerStocks)` 재계산 추가. API 응답에 갱신된 product 전체 데이터 포함 |
| `app/(main)/inventory/barcode/hooks/useBarcodeScanner.ts` | `refreshProduct(barcode)`, `updateProduct(product)` 함수 추가 |
| `app/(main)/inventory/barcode/components/ProductDetailsModal.tsx` | `onProductUpdate` 콜백 prop 추가. 성공 시 모달 유지 + 재고 즉시 반영. 토스트에 이전→변경 재고 표시 |
| `app/(main)/inventory/barcode/components/BarcodeScannerContainer.tsx` | hook의 `updateProduct`를 모달의 `onProductUpdate`로 연결 |

**검증**
- `npx tsc --noEmit` ✅ 타입 체크 통과
