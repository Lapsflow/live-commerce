# 슈퍼무진 라이브커머스 사용자 가이드

> 최종 업데이트: 2026-05-01

---

## 1. 시스템 개요

슈퍼무진 라이브커머스는 센터 기반의 라이브방송 상품 관리 플랫폼입니다.

**핵심 기능:**
- 라이브 방송 등록/승인/진행 관리
- 본사 + 센터 상품 통합 관리
- 발주서 업로드 및 자동 분리 (본사/센터)
- 바코드 스캔 기반 상품 확인
- 가상계좌 발급 및 결제 처리
- ONEWMS 창고 재고 연동
- 변경 이력 추적 (AuditLog)

**접속 주소:** https://www.supermujin.ai

---

## 2. 로그인 방법

1. 브라우저에서 https://www.supermujin.ai 접속
2. 아이디와 비밀번호 입력
3. "로그인" 버튼 클릭
4. 대시보드로 자동 이동

**로그인 실패 시:**
- 아이디/비밀번호 확인
- 계정이 비활성화된 경우 전체관리자에게 문의
- 5회 이상 실패 시 잠시 후 재시도

## 3. 권한별 사용 흐름

시스템에는 3가지 권한이 있습니다.

### 3-1. 전체관리자 (MASTER)

**UI 라벨:** 전체관리자

**메뉴 구성:**
| 메뉴 | 설명 |
|------|------|
| 전체 통계 | 시스템 전체 현황 대시보드 |
| 사용자 관리 | 모든 사용자 조회/편집/권한 변경 |
| 센터 관리 | 센터 등록/수정/활성화 |
| 계약 승인 | 셀러 계약 승인/반려 |
| 발주 관리 | 전체 발주 조회/처리 |
| 방송 관리 | 전체 방송 승인/거절/관리 |
| 방송 캘린더 | 월간 방송 일정 조회 |
| 상품 관리 | 본사/센터 상품 등록/수정 |
| 센터 상품 현황 | 센터별 상품 모니터링 + CSV 내보내기 |
| 상품 제안 | 셀러 상품 제안 검토 |
| 샘플 요청 | 샘플 요청 관리 |
| 바코드 | 바코드 조회/스캔 |
| 변경 이력 | 전체 시스템 변경 로그 |

**할 수 있는 것:**
- 모든 데이터 조회 (센터 제한 없음)
- 사용자 권한 변경 (MASTER/관리자/셀러)
- 센터 생성/수정/활성화/비활성화
- 방송 승인/거절
- 센터 상품 등록 (센터 선택 드롭다운)
- 엑셀 업로드로 상품 대량 등록
- CSV 내보내기
- 가상계좌 발급
- 세금계산서 발행
- 변경 이력 전체 조회

**할 수 없는 것:**
- 없음 (최고 권한)

---

### 3-2. 관리자 (SUB_MASTER)

**UI 라벨:** 관리자

**메뉴 구성:**
| 메뉴 | 설명 |
|------|------|
| 전체 통계 | 대시보드 |
| 사용자 관리 | 사용자 조회 |
| 발주 관리 | 발주 조회/처리 |
| 방송 관리 | 방송 조회/관리 |
| 방송 캘린더 | 월간 방송 일정 |
| 상품 관리 | 상품 조회/등록 |
| 상품 제안 | 상품 제안 검토 |
| 샘플 요청 | 샘플 요청 관리 |
| 바코드 | 바코드 조회 |

**할 수 있는 것:**
- 담당 범위 내 데이터 조회
- 방송 관리
- 상품 관리
- 발주 처리

**할 수 없는 것:**
- 센터 생성/관리
- 센터 상품 현황 모니터링
- 변경 이력 조회
- 계약 승인

---

### 3-3. 셀러 (SELLER)

**UI 라벨:** 셀러

**메뉴 구성:**
| 메뉴 | 설명 |
|------|------|
| 대시보드 | 개인 판매 현황 |
| 방송 | 방송 등록/조회 |
| 방송 캘린더 | 내 방송 일정 |
| 발주 | 발주서 업로드/조회 |
| 판매 | 판매 실적 조회 |
| 상품 제안 | 상품 제안 등록 |
| 바코드 | 바코드 스캔 (방송 중 활성) |

**할 수 있는 것:**
- 방송 등록 신청 (센터코드 입력)
- 거절된 방송 재신청 (무제한)
- 발주서 업로드
- 바코드 스캔 (활성 방송 중에만)
- 상품 제안 등록
- 샘플 요청 (5회 제한)
- 개인 판매 실적 조회

**할 수 없는 것:**
- 다른 셀러 데이터 조회
- 상품 등록/수정 (제안만 가능)
- 방송 승인/거절
- 센터 상품 등록
- 엑셀 업로드
- 사용자 관리
- 변경 이력 조회
- 원가(공급가) 확인

## 4. 주요 기능별 가이드

### 4-1. 사용자 관리

**접근:** 전체관리자, 관리자

**사용자 목록 조회:**
1. 좌측 메뉴 > "사용자 관리" 클릭
2. 검색창에서 이름/아이디 검색
3. 권한별 필터 가능

**사용자 정보 수정:**
1. 사용자 목록에서 "편집" 버튼 클릭
2. 이름, 연락처, 권한 등 수정
3. "저장" 클릭

**권한 종류:**
- 전체관리자: 시스템 전체 관리
- 관리자: 제한된 관리 기능
- 셀러: 판매 활동만

---

### 4-2. 상품 관리

**본사 상품 vs 센터 상품 차이:**

| 구분 | 본사 상품 | 센터 상품 |
|------|----------|----------|
| 등록 주체 | 전체관리자 | 전체관리자 (센터 선택) |
| 상품 코드 | 일반 코드 | C{센터번호}-{순번} |
| 가격 설정 | 본사 기준 | 센터별 독립 |
| 발주 분리 | 본사 책임 | 센터 책임 |
| 바코드 | 일반 바코드 | 센터 전용 바코드 |

**상품 등록 (전체관리자):**
1. 좌측 메뉴 > "상품 관리" 클릭
2. "상품 등록" 또는 "센터 상품 등록" 선택
3. 센터 상품인 경우 소속 센터 선택
4. 상품명, 바코드, 판매가, 공급가, 원가, 재고 입력
5. "등록" 클릭

**엑셀 업로드 (전체관리자만):**
1. "엑셀 업로드" 버튼 클릭
2. 양식에 맞는 엑셀 파일 선택
3. 미리보기 확인 후 업로드

**바코드 가격 4단계 바:**
- 공급가 / 최소판매가 / 권장판매가 / 최대판매가
- 네이버 쇼핑 시세 비교 표시

---

### 4-3. 방송 등록 + 승인 흐름

**셀러 → 방송 등록:**
1. 좌측 메뉴 > "방송" 클릭
2. "방송 신청" 버튼 클릭
3. 방송명, 일시, 센터코드 입력
4. "신청" 클릭
5. 상태: "대기중" (PENDING)

**전체관리자 → 방송 승인/거절:**
1. 좌측 메뉴 > "방송 관리" 클릭
2. 대기중 방송 확인
3. "승인" 또는 "거절" 클릭
4. 거절 시 사유 입력 필수

**셀러 → 거절 후 재신청:**
1. 거절된 방송에서 "재신청" 버튼 클릭
2. 일정 수정 후 재신청
3. 재신청 횟수 제한 없음

**방송 진행:**
1. 승인된 방송의 "시작" 버튼 클릭
2. 방송 중 바코드 스캔 활성화
3. 방송 종료 시 "종료" 버튼 클릭

**알림 발송 시점:**
- 방송 신청 시 → 관리자에게 알림
- 승인/거절 시 → 셀러에게 알림
- 방송 당일 07시 → 셀러에게 리마인더
- 방송 1시간 전 → 셀러에게 임박 알림
- 방송 시작/종료 시 → 관리자에게 알림

---

### 4-4. 발주서 처리

**셀러 → 발주서 업로드:**
1. 좌측 메뉴 > "발주" 클릭
2. "발주 등록" 클릭
3. 발주 정보 입력 (상품, 수량, 가격)
4. 본사 상품과 센터 상품이 혼재된 발주 가능

**자동 분리:**
- 시스템이 상품 코드 기준으로 자동 분리
- 본사 책임 상품 → 본사 발주
- 센터 책임 상품 → 해당 센터 발주
- 발주 목록에서 "(본사 책임)" / "(센터 책임)" 라벨 표시

**발주 상태 흐름:**
PENDING → PAID → SHIPPED → DELIVERED → COMPLETED

**가상계좌 발급 (전체관리자):**
1. 발주 상세 페이지에서 "가상계좌 발급" 클릭
2. 은행, 금액 확인
3. 발급된 계좌번호를 셀러에게 안내 (자동 알림)

**세금계산서 발행 (전체관리자):**
1. 결제 완료(PAID) 상태인 발주에서 "세금계산서 발행" 클릭
2. 공급자/공급받는자 정보 확인
3. 발행 클릭

---

### 4-5. 변경 이력 조회

**접근:** 전체관리자만

1. 좌측 메뉴 > "변경 이력" 클릭
2. 기간, 작업유형, 사용자별 필터
3. 변경 전/후 데이터 비교 가능

**기록되는 항목:**
- 사용자 정보 변경 (권한, 활성화 등)
- 상품 등록/수정/삭제
- 방송 상태 변경 (승인/거절/시작/종료)
- 발주 상태 변경
- 센터 생성/수정
- 세금계산서 발행

## 5. 자주 묻는 질문 (FAQ)

**Q: 비밀번호를 잊었습니다.**
A: 전체관리자에게 연락하여 비밀번호 초기화를 요청하세요.

**Q: 방송이 거절되었습니다.**
A: 거절 사유를 확인하고, 일정/내용을 수정하여 "재신청" 하세요. 재신청 횟수 제한은 없습니다.

**Q: 바코드 스캔이 안 됩니다.**
A: 활성 방송 중에만 센터 상품 바코드 스캔이 가능합니다. 방송이 시작되었는지 확인하세요. 본사 상품 바코드는 방송 상관없이 조회 가능합니다.

**Q: 발주에서 본사/센터 상품이 섞여 있습니다.**
A: 시스템이 자동으로 분리합니다. 발주 목록에서 "(본사 책임)"과 "(센터 책임)" 라벨을 확인하세요.

**Q: 샘플 요청이 안 됩니다.**
A: 샘플 요청은 계정당 5회로 제한됩니다. 이미 5회를 사용했다면 전체관리자에게 문의하세요.

**Q: 상품 원가(공급가)가 보이지 않습니다.**
A: 셀러 권한에서는 원가가 표시되지 않습니다. 판매가만 확인 가능합니다.

**Q: 센터 상품 현황 페이지에 접근이 안 됩니다.**
A: 전체관리자 전용 메뉴입니다. 권한이 필요하면 전체관리자에게 문의하세요.

## 6. 문제 발생 시 대처

### 로그인 불가
1. 아이디/비밀번호 재확인
2. Caps Lock 확인
3. 다른 브라우저로 시도
4. 계속 실패 시 전체관리자에게 연락

### 페이지 로딩 오류
1. 브라우저 새로고침 (F5 또는 Cmd+R)
2. 브라우저 캐시 삭제 (Ctrl+Shift+Delete)
3. 다른 브라우저로 시도
4. 계속 발생 시 전체관리자에게 연락

### 데이터가 표시되지 않음
1. 필터 조건 확인 (날짜, 상태 등)
2. 검색어 오타 확인
3. 페이지 새로고침
4. 권한 확인 (셀러는 본인 데이터만 표시)

### 긴급 연락
- 전체관리자에게 직접 연락
- 시스템 장애 시 Vercel 상태 페이지 확인
